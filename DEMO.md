**Статус:** подготовленный автором план, ожидает совместного согласования и запуска с разработчиком. Описанные результаты ожидаемые, а не фактически полученные. Реализация пока отсутствует.

## Подготовка

Автор A объясняет назначение, стихию, контракт и тесты. Разработчик D показывает реализацию, объясняет принятые решения и запускает демонстрацию. Вместе фиксируют проверенный коммит и результат в ACCEPTANCE.md.

На экране: иллюстрация, SPEC.md, TEST_CASES.md и терминал. Python 3.10+, запуск из корня проекта. Весь набор: `python -m unittest discover -s tests -t . -v`.

## Демонстрация 1. Доставка через бурю (TC-33)

```bash
python -m unittest tests.test_scenarios.TestScenarios.test_tc33_delivery -v
```

- Раскрыть паруса и взлететь: энергия 100 → 95.
- Пройти 10 км при ветре 20: время 0.5 ч, энергия 85.
- Изменить ветер на 40, пройти 20 км: время 0.5 ч, энергия 45.
- Сесть и сложить паруса: путь 30 км, энергия 45, на земле.

Пояснение A: ветер увеличивает скорость; шторм удваивает расход на управление. Полёт остаётся связан с воздушной стихией.

## Демонстрация 2. Штиль и аварийная посадка (TC-34)

```bash
python -m unittest tests.test_scenarios.TestScenarios.test_tc34_calm -v
```

Показать отказ взлёта при ветре 0, успешный полёт при 20, посадку при исчезновении ветра и необходимость повторного takeoff после восстановления потока. Итог: 15 км, 75 энергии, в воздухе. Аварийная посадка — успешное событие без исключения.

## Демонстрация 3. Потеря парусов (TC-36)

```bash
python -m unittest tests.test_scenarios.TestScenarios.test_tc36_torn_sails -v
```

При массе 200 четыре паруса ещё держат аппарат, три уже нет. Показать посадку, ремонт на земле и новый вылет. Итог: 30 км, 60 энергии, шесть парусов, в воздухе.

## Демонстрация 4. Точный бюджет и корректная ошибка (TC-37, TC-13)

```bash
python -m unittest tests.test_scenarios.TestScenarios.test_tc37_last_charge -v
python -m unittest tests.test_skvoznyak.TestSkvoznyak.test_tc13_move_validation -v
```

Ровно 5 энергии хватает на взлёт; с нулём аппарат удерживается, но двигаться не может. Посадка бесплатна, зарядка разрешена только на земле. В `move(0, 123)` ошибка типа второго аргумента имеет приоритет перед нулевым расстоянием. Тесты дополнительно проверяют атомарность отказа.
