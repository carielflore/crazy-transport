# Ревью ТЗ: небесный парусник «Сквозняк»

**Ревьюер B**: Ермолинская Юлия (№6)  
**Проверяемые документы:** `SPEC.md`, `TEST_CASES.md` 
**Автор ТЗ:** Ивчук Михаил Петрович


## R-1. Неоднозначность — TC-11

**Источник:** `TEST_CASES.md`, TC-11.

Входные данные записаны сокращённо: `max=50/12; 6/3 паруса`, а ожидаемое время указано как `0.5 / 10÷12 / 1`. Из записи не вполне очевидно, какое значение ожидается для каждой комбинации параметров.

**Предложение:** перечислить три отдельные комбинации входных данных и соответствующее ожидаемое время в явном виде. Это позволит однозначно сопоставить каждый результат с конкретным набором параметров.


## R-2. Непокрытые случаи — допустимые значения конструктора

**Источник:** `SPEC.md`, раздел с требованиями к конструктору; `TEST_CASES.md`, модульные тесты конструктора.

Спецификация допускает создание объекта с массой от 1 до 10000 кг и ветром от 0 до 100. При этом масса свыше 300 кг и ветер за пределами рабочего диапазона полёта сами по себе не должны препятствовать созданию объекта.

В тест-кейсах важно отдельно проверить эти допустимые случаи: создание объекта с массой больше 300 кг и создание объекта при значении ветра, при котором полёт невозможен. Проверка только граничных и недопустимых значений конструктора не подтверждает это поведение.

**Предложение:** добавить тесты, подтверждающие успешное создание объекта с массой больше 300 кг и при допустимом для конструктора ветре, не подходящем для полёта.


## R-3. Противоречие / недостаточная проверка приоритета исключений

**Источник:** `SPEC.md`, раздел с приоритетом исключений при взлёте; `TEST_CASES.md`, TC-07 и TC-08.

В `SPEC.md` явно задан порядок проверки ошибок при взлёте: `AlreadyAirborne`, `SailsFolded`, `SailsDamaged`, `BadWind`, `Overloaded`, `NoEnergy`. Однако TC-07 и TC-08 проверяют отдельные ошибки, но не подтверждают, что при одновременном выполнении нескольких условий выбрасывается исключение с более высоким приоритетом.

**Предложение:** добавить тест, в котором парусник уже находится в воздухе и одновременно выполняется ещё одно условие отказа, например сложены паруса. Ожидаемое исключение — `AlreadyAirborne`, поскольку оно имеет наивысший приоритет.
