# Небесный парусник «Сквозняк»

Учебный проект по дисциплине «Сборка, тестирование и верификация программного продукта».

**Автор:** Ивчук Михаил Петрович, БСБО-16-23, №7.  
**Стихия:** воздух.  
**Этап:** ТЗ и приемочные тесты, версия 0.1, до заморозки.

![Сквозняк](docs/skvoznyak.png)

Одноместный небесный парусник с кольцом из шести складных парусов. Ловит ветер, летит быстрее в бурю, теряет несущую способность при повреждениях. Энергия нужна для взлета и управления; ветер удерживает аппарат в воздухе. Модель вымышленная, с детерминированными правилами.

## Состав

- [SPEC.md](SPEC.md) — назначение, конструкция, полный публичный контракт, сценарии, границы, исключения, трассируемость.
- [TEST_PLAN.md](TEST_PLAN.md) — область, методы, этапы и критерии тестирования.
- [TEST_CASES.md](TEST_CASES.md) — 40 кейсов: 32 модульных и 8 сценарных (80/20).
- `tests/test_skvoznyak.py` — модульные проверки по AAA.
- `tests/test_scenarios.py` — последовательные сценарии по GWT.
- `tests/helpers.py` — тестовые роли Pilot, Weather, Workshop и общие проверки.
- [RESPONSES.md](RESPONSES.md) — ответы на замечания ревьюеров.
- [CHANGELOG.md](CHANGELOG.md) — история изменений.
- [ACCEPTANCE.md](ACCEPTANCE.md) — порядок и протокол приемки.
- [DEMO.md](DEMO.md) — предварительный план совместной демонстрации с ожидаемыми результатами.
- [PRESENTATION.md](PRESENTATION.md) — предварительный план совместной защиты.
- [AUTHOR_CHECKLIST.md](AUTHOR_CHECKLIST.md) — проверка комплектности и незавершенные этапы.
